# 🤖 Premium AI Chatbot

A modern, highly responsive, and aesthetically premium AI Chatbot built with vanilla HTML, CSS, and JavaScript. This project integrates the **Gemini API** to provide intelligent responses with rich text formatting.

![Project Preview](https://via.placeholder.com/800x400?text=Premium+AI+Chatbot+Preview) 
*(screenshot)*

## ✨ Features

- **💎 Premium UI/UX**:
  - Glassmorphism design with deep gradient backgrounds.
  - Smooth animations for chat messages and interactions.
  - Fully responsive layout for Desktop and Mobile.
  
- **📝 Rich Markdown Support**:
  - Renders **Bold**, *Italic*, and standard Markdown formatting.
  - includes **Syntax Highlighting** for code blocks (using `highlight.js`).
  
- **⚡ Smart Functionality**:
  - **Auto-expanding Input**: Text area grows as you type.
  - **Secure API Management**: Use your own Gemini API key (stored locally in your browser, never on a server).
  - **Chat History**: Persists your conversations using LocalStorage.
  - **Theme Toggle**: Switch between Dark (Default) and Light modes.

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Libraries**: 
  - [Marked.js](https://marked.js.org/) (Markdown Parsing)
  - [Highlight.js](https://highlightjs.org/) (Code Syntax Highlighting)
- **API**: [Google Gemini API](https://ai.google.dev/)
- **Font**: [Outfit](https://fonts.google.com/specimen/Outfit) (Google Fonts)

## 🚀 How to Use

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/Piyush26s/chat-bot.git
    cd chat-bot
    ```

2.  **Open the Project**:
    Simply open the `src/index.html` file in your web browser.

3.  **Set Up API Key**:
    - Click the **Key Icon** 🔑 in the bottom right controls.
    - Enter your [Gemini API Key](https://aistudio.google.com/app/apikey).
    - Start chatting!
